# To-Do Application

A lightweight, standalone task management web application built with Java, Spring Boot, and Thymeleaf.

## Features
- **Task Management**: Create, edit, update, and track daily tasks.
- **Due Dates**: Set and monitor deadline targets for each task.
- **Dynamic UI**: Server-side rendering using Thymeleaf templates.

## Tech Stack
- **Backend**: Java 21, Spring Boot (MVC)
- **Frontend**: Thymeleaf, HTML5, CSS3
- **Build Tool**: Maven
